# Idea: Control Tower Upgrades Require Three Converging Inputs

## The Idea
Upgrading the control tower isn't a single resource spend. It requires three distinct inputs that all have to be present simultaneously — one from each major game activity. No single pillar is sufficient. All three have to converge.

## The Three Inputs

### 1. Wave Resource
- A combat-exclusive drop from surviving waves
- Cannot be manufactured, cannot be found in Tower contracts
- The only source is actively fighting and surviving
- Supplemental waves give smaller quantities, biome boss wave gives a major drop
- This is what makes defense mandatory in the loop — you literally cannot upgrade without it

### 2. Tower Materials / Blueprints
- Knowledge and components recovered from Tower contract completion and floor discoveries
- Each upgrade tier requires materials from the appropriate contract tier
- Ties Tower progression directly to base capability

### 3. Character-Manufactured Component
- A specific component that requires a class at a sufficient level to manufacture
- The class has to know how to make it — that knowledge comes from leveling
- Different upgrade types may require different classes
- This is why leveling multiple classes in the same world has value

## Why Three Inputs
- Each pillar of the game (factory/defense/Tower) contributes something nothing else can substitute
- A player who ignores any one pillar hits a hard wall on tower upgrades
- The interdependency is explicit and visible — players understand why they need to do all three things
- Mirrors the Satisfactory space elevator model: you deliver specific things to unlock a tier

## What Each Upgrade Unlocks
- All four tower rings expand (zone of influence, terminal coverage, power range, bot radius)
- Next wall tier becomes buildable
- Next production tier unlocks (via the class that manufactured the component)
- New resource scanner type unlocks
- Drone count and patrol pattern improves

## Open Questions
- Are there multiple upgrade paths or is it a single linear tier system?
- Does the wave resource stack between waves or does it decay if unused?
- Can upgrades be partially completed — e.g. you have inputs 1 and 2 but not 3 yet?
