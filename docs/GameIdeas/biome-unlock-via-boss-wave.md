# Idea: Biome Unlock via Boss Wave

## The Idea
There are four biomes total. Each one is unlocked by surviving a climactic boss wave tied to that biome's ecosystem. Until you survive it, waves keep escalating. Once you do, waves stop entirely for that biome and a new one opens up for expansion.

## The Threat Meter
- Every factory upgrade, new production line, and base expansion raises a global threat level
- Supplemental waves arrive proportional to threat — bigger base, harder and more frequent waves
- The threat meter fills toward a ceiling — when it peaks, the biome boss wave triggers
- Players can see the meter filling and prepare accordingly

## Supplemental Wave Rewards
- Wave enemies drop salvage, biome-specific materials, and wave-exclusive resources
- Wave-exclusive resource cannot be manufactured or found in the Tower — only from combat
- Fast clear bonus on top of standard drops
- Surviving waves earns control tower upgrade components (one of three required inputs)

## The Biome Boss Wave
- Everything the ecosystem has — coordinated assault, apex fauna
- Hardest fight in the current biome
- Surviving it: threat meter resets, supplemental waves stop permanently in that biome, new biome unlocks
- The new biome has unique resources unavailable in any previous biome

## Four Biomes = Four Supply Chains
- Each base produces something the others can't
- Unlocking a new biome doesn't replace the first base — it extends the operation
- By endgame you're managing a network of four bases, the first three silent and running, the fourth still being fought for

## Open Questions
- Does the biome boss wave scale with player count or stay fixed?
- Can you delay the boss wave by intentionally keeping the threat meter below the ceiling?
- What happens if you abandon a base after clearing its biome?
