# Idea: Class System — Former Slopworks Employees

## The Idea
At character creation you pick your former Slopworks job title. This determines your melee weapon, your combat profile, and your exclusive crafting recipes. Classes don't push you toward different playstyles outside of combat — everyone builds the factory, everyone manages resources. The difference is what you bring to a fight and what you can manufacture for it.

## The Four Classes

### Fabricator — Former Production Line Supervisor
- **Melee**: Sledgehammer — slow wind-up, massive AOE, staggers groups
- **Combat style**: Heavy brawler, high single-hit damage, low mobility
- **Exclusive recipes**: Molten Rounds, Slag Grenade, Forge Charge
- **Progression unlocks**: Higher production tiers, industrial processing components for tower upgrades

### Warden — Former Facility Security Contractor
- **Melee**: Breaching Hammer — faster swing, hard knockback, crowd control
- **Combat style**: Balanced, disruption-focused, protects teammates
- **Exclusive recipes**: Concussion Rounds, Flashbang, Barrier Charge
- **Progression unlocks**: Higher wall tiers, perimeter defense components for tower upgrades

### Contractor — Former Site Demolition Specialist
- **Melee**: Rebar Flail — fast, unpredictable arc, hits multiple targets
- **Combat style**: Aggressive skirmisher, highest mobility and ranged damage
- **Exclusive recipes**: Demo Charge, Breach Rounds, Frag Cluster
- **Progression unlocks**: Deeper Tower contract access, demolition components for tower upgrades

### Technician — Former Electrical & Systems Engineer
- **Melee**: Arc Welder Torch — short range, continuous damage, effective vs armored
- **Combat style**: Utility fighter, mobile disruptor, best commander at the terminal
- **Exclusive recipes**: Arc Rounds, EMP Grenade, Shock Mine
- **Progression unlocks**: Advanced drone and power grid tiers, electrical components for tower upgrades

## XP — Combat Only, Shared
- All XP comes from combat: Tower kills, wave kills, roaming monster kills
- XP is shared across the party — everyone in the session levels together
- More players = harder enemies = more XP per session
- No class-specific XP sources — no friction between players

## Class Level Is Tied to the World, Not the Player
- At game start you pick from whichever classes aren't already taken by other players
- Each class has a level in that world — not per player account
- Whoever picks Fabricator inherits the Fabricator's current level and its unlocks
- A world's classes can be at different levels depending on what the group focuses on

## Manufacturing Unlocks Travel With the Character
- As a class levels it unlocks higher production tiers and tower upgrade components
- These unlocks are not tied to a base — they travel with the class to every base in the world
- A leveled Fabricator building in biome 2 can build tier 3 belts from day one there
- This is the main reason to level multiple classes in the same world

## What Classes Are NOT
- Classes don't give passive bonuses to the base while logged in
- Classes don't push you toward different non-combat activities
- Classes don't gate building, resource management, or factory work
- No special powers or mutations — grounded in job expertise and crafted equipment

## Open Questions
